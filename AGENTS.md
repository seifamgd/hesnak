## Project rules
- Azkar content lives only in `src/data/azkar.ts` with shape `{ id, category, text, repeat, virtue, source }`; add only authentic (sahih/hasan) hadith — accuracy is the product.
- All user state is client-side in localStorage via `src/lib/store.ts` (useSyncExternalStore, server snapshot = defaults) — no backend needed, avoids hydration mismatch.
- Service worker is generated by vite-plugin-pwa and registered only through `src/lib/pwa.ts`, which refuses preview/iframe/dev hosts.
